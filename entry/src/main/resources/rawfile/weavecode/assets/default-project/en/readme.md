# 织码 WeaveCode

> 以代码为线，编织数字世界。  
> One thread. Infinite possibilities.

这是一个极简品牌展示页，采用原生 HTML、CSS 和 JavaScript，无需安装依赖或构建工具。

## 项目结构

```text
WeaveCode/
├── images/
│   ├── icon.png
│   ├── yy.png
│   ├── xc.png
│   └── cs.png
├── index.html
├── script.js
├── styless.css
└── readme.md
```

## 运行方法

1. 保持以上目录结构和图片文件名不变。
2. 在浏览器中打开 `index.html`。
3. 点击右上角语言按钮，可以在中文与英文之间切换。


## 注意

本项目是静态展示页面，不包含用户登录、后端服务或真实在线反馈功能。
