## Corresponding source

For every distributed Weave Code binary and every publicly accessible modified
network version, the public source repository must contain the complete
corresponding source for that exact version, including local modifications,
dependency lock files, build scripts, and installation information required to
produce and run the covered work.

Merely linking to a repository that contains only a license or an incomplete
source snapshot does not provide the corresponding source for a distributed
binary. Release maintainers must verify source-to-artifact correspondence before
publication.

## Third-party components

Third-party components remain subject to their own licenses and notices. The
`NOTICE` file preserves the notice set supplied with the Phoenix-derived runtime.
Individual license files distributed beside components remain controlling for
those components.

Before a public release, regenerate or reconcile the notice set against the
exact dependency versions and extension packages included in that release.

This file records project provenance and release requirements; it is not a
substitute for the license texts or legal advice.
